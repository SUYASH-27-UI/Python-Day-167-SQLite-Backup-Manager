# Python Day 167 – SQLite Database Backup Manager

## Project Description
A Python application that manages employee records using SQLite and creates timestamped database backups.

## Features
- Automatically creates an SQLite database.
- Adds employee records.
- Displays saved employees.
- Creates timestamped database backups.
- Lists available backup files.

## Technologies Used
- Python
- SQLite
- SQL
- OS Module
- DateTime

## Project Files
- `database_backup.py` – Main application.
- `company.db` – Automatically generated database.
- `database_backups/` – Stores backup copies.

## How to Run
Execute `python database_backup.py`.

No external packages are required.

## Learning Outcomes
Learned database operations, SQL queries, SQLite backup functionality, file management, and timestamp generation.
